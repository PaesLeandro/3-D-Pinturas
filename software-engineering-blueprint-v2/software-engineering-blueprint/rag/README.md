# RAG

Use retrieval only when the project has a corpus too large or dynamic for normal repository context, such as product documentation, policies or knowledge bases.

Before adding RAG define:
- authoritative corpus;
- ingestion/update lifecycle;
- chunking/retrieval strategy;
- access-control propagation;
- citation/provenance requirements;
- evaluation set;
- stale-data behavior.

RAG is not required for ordinary application development.
