# Contributing

Before a substantial change:
1. Link or create a SPEC.
2. Keep commits coherent.
3. Add tests with behavior changes.
4. Run local quality gates.
5. Explain migration/deployment impact.
6. Request review for security/architecture-sensitive changes.

Commit messages should describe intent, e.g. `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`.
