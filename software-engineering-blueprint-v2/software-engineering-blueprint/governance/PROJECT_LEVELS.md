# Project Levels

Choose the highest level whose characteristics apply.

## LEVEL 1 — Static / Landing
Typical: static site, portfolio, marketing page.
Baseline: accessibility, responsive UI, SEO, performance, secure headers where applicable, basic CI.

## LEVEL 2 — Application
Typical: authenticated web/mobile application with backend/API.
Add: server-side authorization, input validation, integration tests, migrations, secrets management, structured errors/logging.

## LEVEL 3 — SaaS / Commercial
Typical: multi-user/multi-tenant commercial system, payments, business-critical data.
Add: tenant isolation, auditability, backup/recovery, stronger CI/security scanning, observability, rate limits, deployment/rollback strategy, critical E2E tests.

## LEVEL 4 — Critical / Regulated
Typical: high-impact, regulated, financial, health, public-safety or similarly sensitive system.
Add: formal threat model, stricter access control/audit, data classification/retention, compliance mapping as applicable, disaster recovery objectives, change controls, stronger security testing and operational runbooks.

Classification does not itself prove compliance.
