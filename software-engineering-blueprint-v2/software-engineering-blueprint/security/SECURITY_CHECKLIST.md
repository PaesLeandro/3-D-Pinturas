# Security Checklist

- [ ] Authentication reviewed
- [ ] Authorization server-side
- [ ] Negative authorization tests
- [ ] Input validation
- [ ] Injection risks reviewed
- [ ] Browser threats reviewed where applicable
- [ ] SSRF/file-upload risks reviewed where applicable
- [ ] Secrets absent from source/client/logs
- [ ] Sensitive data minimized
- [ ] Dependency scan
- [ ] Secret scan
- [ ] Rate limiting/abuse considered
- [ ] Audit events considered
- [ ] Threat model updated for high-risk changes
