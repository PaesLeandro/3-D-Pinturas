# Observability

Use signals appropriate to project level.

## Logs
Structured, contextual, no secrets/sensitive payloads.

## Metrics
Track service/business indicators that reveal failure or degradation.

## Traces
Use distributed tracing when request flow spans meaningful service boundaries.

## Alerts
Alert on actionable symptoms, not noise.

OpenTelemetry is a preferred vendor-neutral option when the stack and project level justify it.
