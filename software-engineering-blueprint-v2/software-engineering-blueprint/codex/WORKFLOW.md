# Codex Workflow

## Discovery
Inspect and establish facts.

## Design
For non-trivial work, create/update SPEC and PLAN.

## Execution
Implement one coherent slice at a time.

## Verification
Run targeted tests first, then broader applicable gates.

## Review
Review diff for:
- correctness;
- security;
- regressions;
- unnecessary complexity;
- accidental secrets;
- missing docs/tests.

## Delivery
Report:
- what changed;
- important files;
- tests/gates actually executed;
- remaining risks;
- migrations/deployment steps when applicable.
