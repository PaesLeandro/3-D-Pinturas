# Installation Checklist

When copying into an existing repository:

- [ ] Place folder as `software-engineering-blueprint/` OR adapt paths consistently.
- [ ] Put a root-level `AGENTS.md` in the repository. Prefer the Blueprint AGENTS as baseline and merge existing repository instructions deliberately.
- [ ] Fill `context/PROJECT_CONTEXT.md`.
- [ ] Choose project level.
- [ ] Fill architecture/security baseline from verified code.
- [ ] Configure real quality-gate commands.
- [ ] Adapt GitHub workflows to the actual stack.
- [ ] Ensure `.env`/secrets are ignored.
- [ ] Create first SPEC for the next substantial change.
- [ ] Commit Blueprint separately when practical.

Do not overwrite project-specific rules without reviewing them.
